ARRELS DEL FOC — Web
=====================
Resumen operativo (actualizado 20/08/2026). Sirve para retomar el proyecto en cualquier
momento o en otra conversación con Claude.


1) QUÉ ES ESTO
----------------
Web estática (HTML + CSS + JS puro, sin build ni framework) del restaurante Arrels del
Foc, en Martinet (Cerdanya). 4 páginas:
  - index.html    Inicio (hero con vídeo, experiencia, equipo-CTA, opiniones, contacto)
  - carta.html    Carta completa (Entrants/Principals/Postres/Begudes/Vins)
  - equip.html    Nuestra cocina + equipo (Bruno, Rodrigo, Valeria)
  - reserves.html Reservar (llamar / WhatsApp)
Todas comparten styles.css + script.js. 4 idiomas (CA por defecto / ES / FR / EN) con un
selector arriba a la derecha — el cambio de idioma es 100% JavaScript en la misma URL,
NO hay rutas separadas por idioma (importante: Google solo indexa la versión catalana,
la que está en el HTML crudo).


2) CÓMO SE PUBLICA (flujo de trabajo)
----------------------------------------
Carpeta local:  C:\Users\sofia.gimenez\Desktop\Arrels del Foc - Web
Es un repo git conectado a GitHub, y GitHub conectado a Netlify con auto-deploy.

Para publicar un cambio:
  git add -A
  git commit -m "mensaje"
  git push
...y en ~1 minuto el cambio ya está en vivo en arrelsdelfoc.com. No hay que hacer nada
más (no hay build, no hay que subir carpetas a mano).

Vista previa local sin publicar: doble clic en index.html (o cualquier .html), funciona
sin servidor. Ojo: los cambios de idioma/JS funcionan igual abriendo el archivo directo.

4) QUÉ YA ESTÁ HECHO (estado real a 20/08/2026)
---------------------------------------------------
- Web completa, mobile-first, en vivo en el dominio propio con SSL.
- Narrativa de marca: "raíces argentinas propias + producto de proximidad del Pirineo,
  con el fuego como protagonista" — YA NO es "fusión argentina-catalana" (se sacó esa
  narrativa a pedido de la clienta/dueño; si se retoca texto en el futuro, mantener esta
  línea, no volver a mencionar "fusión catalana").
- Carta completa con fotos reales en casi todos los platos, precios, 4 idiomas.
- Horario real día a día (no genérico), corregido y verificado.
- Footer, header, redes sociales, iconos — todo revisado y funcionando en los 4 idiomas.
- SEO técnico completo: robots.txt, sitemap.xml, canonical tags, Open Graph/Twitter
  Card, datos estructurados JSON-LD tipo Restaurant (dirección, teléfono, horario,
  geo, redes, rating 5/5), un único <h1> por página, alt text descriptivo en todas
  las imágenes, titles/meta descriptions con keywords de Cerdanya/Andorra/Pirineos.
  Hreflang NO implementado (no tiene sentido sin URLs separadas por idioma — sería
  un cambio de arquitectura más grande, pendiente de decidir si se quiere a futuro).
- Rendimiento: vídeo del hero comprimido de ~20MB a ~3-4MB (ffmpeg instalado en esta
  máquina si hace falta comprimir algo más — winget install --id Gyan.FFmpeg).
